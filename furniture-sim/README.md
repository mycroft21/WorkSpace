# 55A 가구 배치 시뮬레이터

하우스토리 55A(전용 55.92㎡) 평면도 위에 실제 mm 치수로 가구를 배치해 보는 단일 HTML 도구입니다.
`55A-furniture-simulator.html` 파일 하나를 브라우저(PC·태블릿)에서 열면 바로 동작합니다. 서버·빌드·외부 라이브러리가 없습니다.

## 주요 기능

- 평면도 이미지 배경(내장) + 추정 안목 치수로 그린 방·벽·문(회전 반경)·창문·고정 설비
- 가구 라이브러리 드래그 앤 드롭, 이동·회전(15°/90°)·모서리 크기 조절, 방향키 미세 이동, 복제·삭제
- 10/50/100mm 스냅, 선택 가구의 벽까지 거리와 가장 가까운 가구까지 거리 표시
- 검증: 가구 충돌(빨강), 벽체·방문 개폐 공간 침범(빨강), 여유 공간 부족(주황)
  - 여유 공간: 침대 측면 500, 책상 의자 800, 옷장 앞 800, 소파 앞 1,200, 식탁 의자 750, 냉장고 앞 900mm (권장값, 가구별로 수정 가능)
- 시나리오 A/B/C 기본 배치, 브라우저 저장소에 이름별 저장·불러오기, JSON 파일 저장·열기
- PNG(현재 화면)·CSV(가구 목록과 검증 결과) 내보내기
- 배경 이미지 위치·크기·투명도·잠금, 2점 축척 보정, 방·문 치수 표 편집, 구조 JSON 직접 편집

## 치수에 대한 주의

방 치수는 도면의 구획 치수(12,480 × 8,450, 2,700/2,100/3,600/3,300 등)와 이미지 비율로 **추정**한 안목 치수입니다.
벽 두께·문틀·창틀은 반영되지 않았으므로 실측 뒤 `구조·배경` 탭에서 수정하세요.

## 검증 방법

```
node test1.js   # Playwright로 로드·시나리오 전환·드래그·단축키·실행 취소·내보내기를 점검 (스크립트는 세션 스크래치에 있음)
```
